# Configuration of mathrix-education-cluster

This repository is the configuration of the Google Cloud Kubernetes Engine `mathrix-education-cluster`.

It is proudly written and maintained by :

- Valentin Pollart <valentin@mathrix.fr>
- Mathieu Bour <mathieu@mathrix.fr>

## Workflow:

The configuration is automatically applied to the cluster when a commit is pushed on the `master` branch.
The *compilation* is handled by Google Cloud Build.
